# InstaZen 🧘‍♂️

InstaZen is an Android app designed to provide a more focused Instagram experience by prioritizing **Instagram Messages (DMs)** while restricting access to distracting areas of Instagram.

The goal is simple: **stay connected without getting pulled into endless scrolling.**

## ✨ Features

- 💬 **DM-focused Instagram experience**
  - Access Instagram Messages directly.
  - Other Instagram sections are restricted while focus mode is active.

- ⏱️ **15-minute daily exception**
  - Get up to 15 minutes of unrestricted Instagram access each day.
  - The time is cumulative rather than a single 15-minute session.

- 🔄 **Automatic restriction**
  - When the exception time is unavailable or expires, InstaZen returns to the focused DM experience.

- ⏸️ **Pause / Resume**
  - Temporarily pause the daily exception timer when needed.

- 🌐 **Built-in Instagram experience**
  - Instagram runs inside InstaZen rather than requiring users to switch to another browser.

## 🎯 Why InstaZen?

Instagram can be useful for communication, but it can also become a source of distraction.

InstaZen is built around a simple idea:

> **Keep the connection. Reduce the distraction.**

Instead of completely blocking Instagram, InstaZen prioritizes the part many people actually need — **Messages** — while providing a limited amount of time for everything else.
